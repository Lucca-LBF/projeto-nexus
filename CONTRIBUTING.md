# Guia de Contribuição - Projeto Nexus (Simulador Bzu)

Primeiramente, obrigado por se interessar em contribuir com o **Projeto Nexus (Simulador Bzu)**! 🎉

Este documento estabelece as diretrizes para garantir que o desenvolvimento do nosso sistema (baseado em Django, Pandas, NumPy e Plotly) continue organizado, escalável e de fácil manutenção. Siga as instruções abaixo para relatar bugs, sugerir melhorias ou enviar seus *Pull Requests* (PRs).

---

## 🐞 1. Como relatar Bugs ou sugerir Funcionalidades

Nós utilizamos o **GitHub Issues** e o nosso quadro no **Jira** para rastrear tarefas e bugs. 

- **Quadro Jira:** [Acessar o Jira do Projeto Nexus](https://cesar-team-wuiwsqgi.atlassian.net/jira/software/projects/KAN/list?jql=project%20%3D%20KAN%20ORDER%20BY%20cf%5B10019%5D%20ASC)
- **Encontrou um bug?** Abra uma *Issue* no [GitHub Issues](https://github.com/Lucca-LBF/projeto-nexus/issues) descrevendo o problema, o comportamento esperado e os passos para reproduzir o erro (inclua prints, se possível).
- **Tem uma ideia nova?** Abra uma *Issue* com a tag `enhancement` (melhoria) e explique como a funcionalidade agregaria valor ao Simulador Bzu ou ao Dashboard.
